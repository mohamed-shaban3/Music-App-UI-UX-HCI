# 🎵 Music Streamer App - UI/UX Design
### Human-Computer Interaction (HCI) Project

This project showcases a comprehensive mobile UI design for a music streaming platform, emphasizing user-centered design principles and intuitive navigation.

## 📱 Project Overview
The design includes a complete user journey, from authentication to media playback, featuring specialized sections for Music, Podcasts, and Quran.

![Full Design Overview](Screenshot%202026-05-14%20193216.png)

## ✨ Key HCI Features Implemented
* **Visual Hierarchy:** Essential controls like Play/Pause are prominently placed for quick interaction.
* **Consistency:** Unified color palette and iconography across all screens.
* **Accessibility:** High-contrast Dark Mode design to reduce eye strain.

## 🛠️ Design Tools
* **Figma** (Layout, Prototyping, and Components)
